# Description

This API folder is not called anywhere in this application. Its sole purpose is as reference to the previous DB schema constructed using Mongo. Please use these files as reference to the schema structures and substructures used in the PocketBase DB.

### Information on schema structure can be found as follows:

apiContext/schemas/userSchema.js --> Overview of main 'member_snapshot' schema structure

apiContext/schemas/DevContextNOTES/USERINFO.txt --> Explanation of schema parameter names

apiContext/schemas/subschemas/ --> Folder of additional subschema's used in userSchema.js
